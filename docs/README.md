# docs

Reference material that is not part of the build.

| Path | What it is |
|---|---|
| `ANALYSIS.md` | Read-only analysis of the whole codebase (folders, endpoints, flags, dead code, secrets scan) |
| `RESTRUCTURE_PLAN.md` | The approved plan for the restructure |
| `RESTRUCTURE_RESULTS.md` | What the restructure changed (written at the end) |
| `brand/` | Logos, icons and the brand guide |
| `design-reference/` | Screen mock-ups (`*.dc.html`); `make landing-screens` renders them |
| `legal/` | Terms, privacy, cookies, grievance officer, refunds, community guidelines |
| `archive/` | Finished one-off documents: `AUDIT.md` (pre-beta audit), `PROMPTS.md` (session prompts) |

The working docs stay in the repo root because the tests and CLAUDE.md expect them there:
CLAUDE, PRODUCTION, LAUNCH, BACKLOG, PROGRESS, DESIGN, RUNBOOK, COMMANDS, FRONTEND_HANDOFF.

No command to run or test here. Edit the Markdown and commit.
