Written 2026-11-07. Nothing has been moved or deleted. Strike any item you don't want; Phases 3–4 do only what is left.

## 1. Approach: almost no moves

The repo already has the shape you described (`backend/`, `apps/`, `packages/`, `scripts/`, `docs/`, plus deploy and infra folders).
The renames in your example would be expensive and risky, so they are **not** proposed:

| Idea | Why not |
|---|---|
| `docker/`, `deploy/gcp/` → `infra/` | 11 and 22 files reference those paths. This includes **runtime backend code** (`circuit/settings.py`, `core/backup.py`, `core/jobhealth.py`, `run_jobs.py` read `deploy/gcp/app.toml`), `scripts/gcp.py`, the workflows, dependabot, the Dockerfile and 6 tests. |
| `apps/app` → `apps/web` | Touches `vercel.json`, Makefile, CI, CLAUDE.md and the tests. |
| Root docs (PRODUCTION, DESIGN, RUNBOOK, …) → `docs/` | 28–134 references each, tests `test_runbook.py` and `test_commands_doc.py` read them, and CLAUDE.md expects them at the root. |
