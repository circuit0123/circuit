# Circuit

A startup ecosystem platform for India: people are matched on what they need and what they can offer.

- Every command you run is a `make` target: see [COMMANDS.md](COMMANDS.md) (`make help` lists them).
- First run: `cp .env.example .env`, then `make setup`, then `make dev`.
- How we build it: [CLAUDE.md](CLAUDE.md). How it runs in production: [PRODUCTION.md](PRODUCTION.md).
- What to build next: [LAUNCH.md](LAUNCH.md). Where we are: [PROGRESS.md](PROGRESS.md).
